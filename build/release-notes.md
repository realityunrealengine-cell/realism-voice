Версия 1.2.2

Исправления
- Установка: исправлена ошибка «Не удалось закрыть Realism Voice» (например, при установке через Wine на Linux или когда PowerShell недоступен).
- Голосовая связь: исправлена ошибка подключения «cannot add presence callbacks … after subscribe()» при повторном входе в звонок.
- Звонок больше не обрывается сам: при проблемах с сетью приложение переподключается до тех пор, пока связь не вернётся, а не выкидывает из канала через минуту.
- Кратковременные сбои связи у собеседника больше не выглядят как его выход из канала: он остаётся в списке, звук не прерывается.
- Полноэкранная демонстрация: выйти можно кнопкой в углу (в полном экране она видна всегда), клавишей Esc или двойным щелчком.
