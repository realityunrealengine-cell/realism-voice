Версия 1.3.1 — безопасность

Ключи устройств и коды безопасности
- Прямые (P2P) сообщения теперь подписываются ключом вашего устройства (Ed25519 + постквантовый ML-DSA-65). Подменить собеседника незаметно больше нельзя.
- В «Настройки → Безопасность → Ключи устройств» показан 60-значный код безопасности для каждого собеседника. Сверьте его с собеседником: если код совпадает, между вами нет посредника.
- Если у собеседника меняется ключ (новое устройство или переустановка), приложение предупреждает об этом. Доверие к любому ключу можно отозвать — P2P с таким устройством перестанет работать.
- В личной переписке с P2P-историей появилась кнопка щита для быстрого перехода к коду безопасности.

Защита данных на компьютере
- P2P-история и очередь неотправленных сообщений теперь хранятся на диске зашифрованными. Ключ защищён Windows и привязан к вашей учётной записи.
- Приложение проверяет свою целостность при запуске и не даёт использовать себя для запуска постороннего кода.

Конфиденциальность на сервере
- Закрыты лазейки, через которые можно было узнать чужие дружбы, блокировки и состав серверов. Работа приложения не изменилась.
